# Inline immersion: reading before animation

The alpha26 display still has alpha24's 75 ms fade-out through zero followed by a 75 ms fade-in. Many independent phrase clocks can create repeated attention demands. Inline reservations measure an imposed Medium weight but can render a different inherited weight; `TextTop` placeholders containing full line-height text also risk different baseline and leading from adjacent native text. Default semantic colors, weight and agreement underlines compound those differences. Interface labels use another renderer, so they do not participate in the same language transition.

## Evidence and limits

- [Kevin Larson, The Science of Word Recognition](https://learn.microsoft.com/en-us/typography/develop/word-recognition) reviews letter recognition, eye movements and contextual/parafoveal preview. English reading involves discrete fixations and regressions; stable upcoming letters and spacing matter. Its reported fixation durations are not an animation specification or measurements of this bilingual UI.
- [Yantis and Jonides, 1984](https://pubmed.ncbi.nlm.nih.gov/6238122/) experimentally studied attentional capture by abrupt visual onsets. Applying that result to recurring UI phrase changes is a design inference, not a direct study of language learning.
- [Designing and Evaluating Livefonts](https://www.microsoft.com/en-us/research/uploads/prod/2018/11/livefonts.pdf) evaluates animated typography for different readers. It does not establish that arbitrary continuous bilingual changes improve comprehension, or that its results transfer to this app.
- [W3C Pause, Stop, Hide](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html) explains why motion and automatically updating content need user control. [Text Spacing](https://www.w3.org/WAI/WCAG21/Understanding/text-spacing) is a resilience requirement for changed spacing, not permission to impose irregular spacing or a universal prescription for one font.

No phone gaze is measured. We must not pretend to change phrases between actual saccades. Touch, scrolling, keyboard visibility, lifecycle and accessibility settings are observable interaction signals; they are useful conservative pauses, not gaze detection.

## Implementation direction

Keep one inline semantic flow and unchanged execution/copy/URL behavior. A replacement changes language, not the control's action or hit region. Body text retains native weight, color and baseline; validated grammar annotations remain available as semantic data rather than a default rainbow competing with reading. Parent icons/backgrounds stay stable while their labels transition.

Native review rejected both a narrow spatial wipe (joined unrelated word pieces) and a full-layout crossfade (ghosted overlapping sentences, especially at2× text). The replacement keeps exactly one native Text layout at every frame. Opacity eases from1 to a readable85% floor; the language changes once at the midpoint, then returns to1. This is a discrete semantic handoff with a shallow360 ms ink fade, not a continuous glyph morph. It never fades through black or overlays source and target layouts. Native links, selection, styling and semantics belong to the actual visible flow, without transparent surrogate hit geometry. Reserve actual maximum source/target geometry at the current font scale; avoid synthetic word columns. Arbitrarily unequal language lengths cannot simultaneously retain natural spacing, identical word positions and identical line breaks. Prefer legible native typography and a stable paragraph envelope; document any remaining geometry tradeoff instead of calling it solved.

Body holds grow with lexical length without the old maximum: source at least6 seconds/300 ms per word; target at least18 seconds/450 ms per word plus6 seconds, and always at least6 seconds longer than source. These are conservative starting values, not validated reading rates. Controls form a calm target-dominant layer (initial tuning: 18 seconds target, 6 seconds source). This is a design starting point, not a validated human-perception threshold. Controls and content use the same transition treatment but need not all change at once. Pause text motion during direct interaction, keyboard entry, backgrounding and touch exploration. Android reduced-motion preference holds a readable language instead of replacing fades with instantaneous automatic swaps. In-place source hold remains available; explicit speech retains its captured flow.

## Qualification gates

Inspect normal and 2× font scale, unequal word counts and long forms, baseline continuity, natural spaces, inherited bold/italic, punctuation, URLs/images and truncation. Capture complete native motion and intermediate frames. Check that no whole phrase vanishes, source/target are not exposed as duplicate lines or semantic children, and phase changes do not change action hit regions. Verify touch/scroll and keyboard pauses, manual source hold, reduced motion, lifecycle resume and captured speech. Publish only synthetic reviewed UI media. Timing and visual quality need user feedback; fixture checks are not a comprehension or language-acquisition study.

## User rejection of alpha27: clean rendering is insufficient

The user reports that alpha27's language switch is too fast to notice and locate. Root personally reviewed extracted native frames, not uninterrupted normal-speed playback. The360ms envelope contained roughly11 frames at30fps or22 at60Hz, but the semantic change still occurred within one frame. The intermediary was shallow whole-text dimming; it gave no local advance cue or persistent change location. Neither frame inspection nor normal-speed footage is a human perceptibility/comprehension study.

[Rensink, O'Regan and Clark (1997)](https://www2.psych.ubc.ca/~rensink/publications/download/PsychSci97-RR.pdf) found that cues aid change identification in scene tasks. [Simons, Franconeri and Reimer (2000)](https://visualthinking.psych.northwestern.edu/publications/Simons_etal_gradual.pdf) showed that gradual changes can also go unnoticed without a visual disruption. Therefore simply making the fade slower is insufficient. [Baudisch and colleagues' Phosphor (2006)](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/02/uist2006-phosphor.pdf) evaluates persistent afterglow explanations for changed interface objects. Applying a local advance cue and lingering trace to bilingual prose is an engineering inference, not an established learning intervention. None of these papers provides a universal frame count for understanding a replacement.

The next prototype preserves fully opaque native glyphs and animates only a localized decorative background. One phrase is prepared, changed and left identifiable before another is considered. Exact stable source IDs map each phrase onto its current native text range after reflow; no union box covers unrelated wrapped words. The4.2s trial timeline is700ms cue ramp,800ms stationary source cue, one semantic handoff,2200ms stationary target cue,500ms cue fade. A single surface coordinator prevents concurrent message/control cues; body cues take priority. Late hydration is staged rather than changing many words silently. Interaction cancels pending work without forcing a future language snapshot. These are prototype timings from user feedback, not psychophysical thresholds.

Qualification must distinguish the whole cue duration from the one-frame semantic switch, inspect timestamped complete transitions, and report what was actually reviewed. Native frame timing/geometry/interaction tests cannot establish that a human noticed, recognized or learned the phrase. Do not describe clean rendering as proof of polished perceptibility.

Native visibility is a cue eligibility input, not a gaze estimate: stable phrase IDs are aggregated per rendered text part under the current reading identity. Glyph bounds are intersected with clipped window bounds, hidden/ellipsized glyphs excluded, and a meaningful visible fraction required. These geometric fractions are tuning choices. Queued cues recheck their intended phrase at lease grant and cancel when it leaves view. Off-screen composed rows and labels cannot consume a visible cue lease. Actual language choices survive visibility changes.

The first alpha28 prototype was rejected during native review: linked body text changed without its local cue, while footer cues occupied approximately86% of a17-second observed interval. Native Text resolves link annotations, so comparing complete annotated strings incorrectly rejected a lexically correct layout. Cue geometry now checks lexical identity instead. Completed cues now enforce a4.2-second global quiet interval; controls initially wait24–120 seconds and hold Italian for120–180 seconds. These timings reduce animation duty, not establish perceptibility. Body cues precede control returns to Italian, then control excursions to English; an active cue is not interrupted by queue priority. Final qualification must use the corrected artifact, not the rejected prototype.
