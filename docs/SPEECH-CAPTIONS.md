# Speech captions and playback

Captions show the current spoken chunk. The latest caption can remain after playback ends; dismissal hides it across later progress updates and app restarts until a different spoken message arrives. Captions do not expose raw model reasoning and are not word-aligned subtitles.

Conversation history remains the sole message surface. Important filters that history, with retained answers actionable in place. Activity and direct Pause/Resume/Clear share compact controls above the composer. Only the current active caption with matching conversation/reader ownership appears there, bounded to two lines; saved or paused speech never becomes a new transcript row. The coordinator follows the same compact policy and offers direct navigation to a queued notification’s source.

Notification speech and manual Speak render chunks through the paired host’s ChatGPT-authenticated native Codex transport without entering voice mode or accessing the microphone. The speech-only connection cannot begin or commit task input and does not replace controller audio. Complete provider turn identity, expected passage, timestamps and drained audio govern successful caching. The phone then uses MediaPlayer, saved cursors and Android media controls. Native availability errors leave the item paused for retry or Clear; there is no silent offline TTS or paid API fallback. Previously rendered offline audio is not reused as native audio, and its old timing cursor resets when rerendered.

Saved playback reuses notification998. Active voice captions use its existing foreground notification1120, then retain them under998 on exit. Native voice captions start with actual playback and finish with playback. Retained updates are silent. Lock-screen visibility follows Android’s notification permission, channel settings and private visibility; the public version says “Unlock to read.” No overlay or lock-screen bypass permission is requested. Physical secure-keyguard presentation and pronunciation require separate verification.

Caption storage is app-private and retains only the latest spoken chunk. [Privacy](../PRIVACY.md) describes which text reaches OpenAI and which data remains on the phone. [Alpha31 coordinator qualification](qualification/coordinator-compact-speech-alpha31.json) records compact controls and draft/keyboard retention. Native saved-speech qualification is versioned separately from older offline playback observations.
