Automatic inline immersion cycling
=================================

Source and Italian variants occupy the same existing paragraph. Each phrase cycles on a deterministic staggered reading-length schedule: source dwell 2.4–8.5 seconds, target dwell at least 1.4 seconds longer. Fade is 75 ms out and 75 ms in; disabled Android animation scale removes the fade. Lifecycle backgrounding suspends timers. A deliberate phrase tap holds its source form; retapping resumes. Existing parent card actions and Markdown URLs retain their own interaction.

Native inline phrase slots reserve the larger measured source/target size at the current font scale and paragraph width. Both short variants fitting the paragraph use one natural phrase slot, avoiding per-word columns. Longer variants are independently greedily split at word boundaries into contiguous phrase chunks; their paired slots are geometric reservation, not claimed linguistic alignment. This lets long phrases wrap across chunks instead of creating a paragraph-wide clipped pill. Unequal chunk counts leave empty reservation in the shorter variant; the resulting spacing is a deliberate stability tradeoff requiring visual review. Measurements use the current theme font and actual heading/Medium weight and genuine Markdown bold/italic only. Only one variant is composed and child text is excluded from accessibility; the parent exposes the currently displayed single flow.

Displayed-text callbacks occur on textual phase changes, not animation frames. Explicit speech of displayed context freezes that exact flow until the displayed speech session ends. During speech, a requested source hold takes effect after the session, preserving visible/spoken agreement.

Pure tests cover schedule boundaries, independent staggering, protected-source preservation, exact variant assembly, and natural phrase chunk decomposition. Synthetic character-size checks are not proof of native font geometry. Native qualification inspected normal and 2× font scale, long multiword wrapping, URL/image/Markdown boundaries, original hold/resume, speech freeze, reduced motion, and actual accessibility. The exact final candidate passed these checks; see [native runtime evidence](inline-cycling-team-alpha24.json) and [delivery verification](alpha24-release-delivery.json). Shorter variants deliberately leave reserved trailing space. Acoustic speech quality is outside this synthetic proof.
