# Transgrammatic immersion acceptance

Latest user direction, 2026-10-16, supersedes intentional partial-language replacement and mixed-language intermediate teaching forms.

The two canonical forms are English vocabulary expressing Italian grammatical structure, and pure Italian. The English form is a grammatical scaffold for reading the Italian: preserve contextual meaning, target phrase order and grammatical correspondence, rather than alternating ordinary English and a structurally different translation. Do not invent English meanings or expose internal teacher annotations as visible clutter.

Render within the ordinary single text flow: no duplicate translations, subtitles, modal help or deliberately hybrid intermediate form. A spatial waterfall naturally has a moving boundary between the two canonical forms; that does not authorize generating a third mixed-language teaching form. Any direct help stays inline at normal readable size.

Reject conspicuous maximum-width lexical slots, artificial blank gaps, oversize reserved boxes and jagged line spacing. Investigate typography and transition geometry together. Avoid exchanging the current padding problem for repeated layout jumps, scroll displacement, clipped glyphs or per-frame text remeasurement. Preserve correspondence where practical without rigidly keeping every differently sized word in an oversized slot.

Use the existing continuous global top-to-bottom/reading-direction cascade across containers, uniform local transition speed, short dwell and ongoing waves. Taps must not suspend the wave. Include labeled controls and ordinary conversation text, and retain supported rich text/tables/links and accessibility. Honor reduced motion.

Verify complete examples, longer Italian/English forms, multi-line paragraphs, controls, large text, scrolling and active typing. Inspect real native motion and frame/main-thread evidence, not only static images or unit totals. Preserve performance, draft/cursor/scroll state and original authenticated messages/actions. Do not call untransformed or unaligned content complete immersion.

Deliver qualified increments alongside the shared rooms/session architecture. Tell the user when the compatible update is available; verify installation separately. Version124 already published before this requirement; it does not implement this new direction.
