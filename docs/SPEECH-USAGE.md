# Native speech activity tracking

Tracking begins with the next build containing this change; it cannot reconstruct previous usage. Notification/manual speech records completed generated chunks, decoded audio duration where Android metadata is available, unknown durations, received bytes, attempts, cancellations, failures and render elapsed time. Settings exposes generated minutes, playback-running minutes, cancelled/failed renders and cached playback requests. Counts are device-local cumulative aggregates in a separate private preferences file, unaffected by Clear speech. No transcripts or identifiers are stored. Clearing app data removes them.

Voice-mode connection time is recorded separately, including idle time, sampled every 30 seconds and flushed at reconnect/leave/destruction. This is not generated speech duration or measured provider billing. A process crash can lose the current unflushed interval. Notification/manual playback time excludes deliberate/transient pauses, samples every two seconds and flushes on completion/release; it does not prove the listener heard the audio. Replay can make played duration exceed generated duration. Unknown-duration renders and audio generated before a failed/cancelled delivery prevent calculating exact unheard minutes.

Automatic notification speech still reads the supplied spoken response, which may be long. Only fresh (up to two minutes old), unread FCM/socket deliveries request automatic speech; history catch-up does not. Existing quiet/DND/channel gates and current-chunk-only generation remain. Before starting fresh native generation, the service checks media volume and acquires audio focus; blocked playback parks the text without opening an audio connection. Transient focus loss during generation cancels it; the service stops its native transport in cleanup. Generation already incurred cannot be refunded. Manual Speak remains explicit.

OpenAI currently documents Voice in Desktop as using the existing Codex usage budget at $0.05 per minute, or 1.25 credits per minute when spending additional credits. Task-model usage is billed separately but shares plan limits. See [official pricing](https://learn.chatgpt.com/docs/pricing#how-much-does-voice-cost). These published rates do not supply a minutes-to-plan-percentage conversion for this device.

Native calls do not return an attributable account-debit figure to this tracker. No dollar, credit, or plan-percentage estimate is shown. Provider rate-limit data remains separate. Exact alpha35 synthetic native checks verify a muted fresh socket notification makes zero native calls, failed rendering increments the failure counter, and Clear works. The optimized public APK passes clean pairing/Settings and muted speech-preview guard checks; its socket-to-speech path is not separately qualified. See [qualification](qualification/speech-usage-alpha35.json). No new real provider inference, positive completed audio-duration/playback qualification, physical-phone installation, attributable billing or audibility is claimed.
