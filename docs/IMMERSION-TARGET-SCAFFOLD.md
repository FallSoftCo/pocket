# Target-grammar immersion

Italian syntax owns the single visible text flow. Vocabulary support replaces content vocabulary in those same positions while retaining grammar-bearing Italian words. It does not restore natural English word order.

For example, **Permessi completi per i nuovi incarichi** cycles to **Permissions full per i new tasks**. **Non sto controllando il modello** supports **Non sto checking il model**. Each lexical counterpart shares a reserved native position and line break. Articles, prepositions, auxiliaries, pronouns, conjunctions and validated negation stay in the target grammar.

The original message remains canonical. The presentation does not rewrite submitted requests or stored transcripts. Target segments supplied by the contextual teacher carry exact offsets, meanings and explicit grammar relationships; the client never derives agreement from spelling or guesses word correspondences by order.

ImmersionGrammarScaffold.kt owns the authored UI vocabulary and projection. The catalog provides both Italian wording and aligned support units, replacing separately maintained interface/voice translation maps. Literal template values remain identical in both forms. Conversation phrases and controls use SharedInlineImmersionText with the same lexical IDs and maximum counterpart dimensions. A shared complementary mask wipes in reading direction without taking the whole line to black.

Unknown or invalid alignment remains target text, rather than a falsely aligned English fallback. Cached contextual plans can supply validated multi-span control wording; cycling itself makes no provider request.

Qualification is recorded in qualification/target-grammar-scaffold-20261012.json. Geometry, actions, clipboard and representative Settings cycling passed on an owned emulator. Fixed reservations still create visible spacing around shorter counterparts. Whole final-source motion review, provider language quality, optimized release qualification and physical phone delivery remain separate work.
