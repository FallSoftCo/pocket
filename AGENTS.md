# NextComp context for repository agents

Read [the documentation index](docs/README.md), [the full product briefing](docs/NEXTCOMP-BRIEF.md) and [capabilities with evidence](docs/CAPABILITIES.md) before describing or changing the product. NextComp is an interaction system for directing ongoing work in the owner's computing environments from Android; coding is one application. Preserve coordinator and direct-session control, useful intermediate answers, actionable notifications, native voice, phone-local execution and optional inline immersion when evaluating a change.

Use [architecture decisions](docs/DECISIONS.md), [privacy](PRIVACY.md), [security](SECURITY.md) and the relevant versioned [verification](docs/VERIFICATION.md). Implementation, synthetic runtime qualification, historical live observations and current phone deployment are different evidence levels. Do not claim exactly-once execution, universal eyes-free use, raw model reasoning access, permanent phone-network recovery or implemented Dots integration.

Track user requirements in [UX-REQUESTS.json](docs/UX-REQUESTS.json). Preserve concurrent work, existing pairing, package/signing identity and private runtime state. Do not publish secrets, private transcripts or deployment-specific captures. User/session instructions and applicable parent instructions remain authoritative.
